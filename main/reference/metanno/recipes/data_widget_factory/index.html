    metanno.recipes.data_widget_factory

    Register shared selections and handles before rendering table, form and text widgets

    DataWidgetFactory [source]

    Bases: TableWidgets, FormWidgets, TextWidgets, PdfWidgets

    Build tables, forms and annotation views that share a PRET Store.

    Widgets created by this factory edit the same data and share row selection. The factory keeps selection separately from the data so navigation does not enter the data undo history.

    Parameters

    PARAMETER DESCRIPTION
    data

    Existing PRET Store, or initial mapping of row lists and DataFrames

    TYPE: Union[Store, Dict[str, Any], Callable[[], Dict]]

    sync

    Used when creating a Store from initial data. False or None keeps edits in the browser. True synchronizes with Python without saving to disk. A file path also saves edits and lets other Python processes open the same Store

    TYPE: Optional[Union[bool, str, PathLike]] DEFAULT: None

    relations

    Parent and child columns used to filter linked tables

    TYPE: Sequence[DataRelation] DEFAULT: ()

    read_only

    Disable mutations from these widgets without changing notebook access to the Store

    TYPE: bool DEFAULT: False

    register_dataframe [source]

    Include a created widget table and its ancestors in the shared browser initialization

    ensure_selected_rows [source]

    Create the shared selection of a Store key, read and written by every widget showing it.

    identities holds the primary keys of the selected rows and row the values of the lead one. Tables keep the positions of these rows themselves, to highlight them.

    deep_get_store staticmethod [source]

    Find the rows shown for a Store key, following a nested key such as notes.entities through the lead selected row of each parent, identified by its primary key

    make_filter_related_tables [source]

    Build the browser function that filters the tables of other Store keys on the primary key of a selected row, for Store keys without a declared DataRelation

    make_select_rows [source]

    Build the browser functions that change a shared selection and update the widgets related to it.

    select_rows is called by tables with the selected rows, and by forms and annotation widgets when no table shows their rows. select_row_id goes through a table of the Store key when there is one, so it scrolls to the row and highlights it.

    create_selected_field_view [source]

    Render a single field from the currently selected row in a store.

    Parameters

    PARAMETER DESCRIPTION
    store_key

    Key pointing to the collection to display.

    TYPE: Any

    shown_key

    Field key to show from the current row.

    TYPE: Any

    fallback

    Value returned when no row is available.

    TYPE: str | None DEFAULT: ''

    RETURNS DESCRIPTION
    Renderable

    Pret component instance displaying the selected field value.

    create_status_bar [source]

    Return a bar showing the last rejected edit or undo of the Store and its connection to Python, place it below the widgets of a notebook output or an app. Factory widgets do not show Store errors themselves

    Parameters

    PARAMETER DESCRIPTION
    show_connection

    Also show whether the Store is connected, disconnected or offline

    TYPE: bool DEFAULT: True
